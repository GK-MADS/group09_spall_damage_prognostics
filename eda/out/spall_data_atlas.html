Section 1

Dataset inventory

Seven run-to-failure gears: four with photos (A, B, C, F), one validation gear (G) and two test gears (D, E). Each run is about 6.15 operating hours at 1,400 rpm; photos are taken of all 28 teeth between runs.

Section 2

Data issues to handle before modeling

Must fix

Exp-A Run-2 is a duplicate

All 372 files in Exp-A_Run-2 have the same MD5 hashes as Run-1: the same sessions (Gear233Run1/Run2) and the same timestamps. About 6.15 h of Exp-A sensor data is missing, not repeated. The photos for Run-2 are distinct. flatten_hdf5.py currently counts these hours twice. Deduplicate by content hash and keep the nominal hour axis so the photo times still line up.

Must fix

Exp-A ran at a different torque

Exp-A ran at 120 ft·lbf and about 129 °F. Every other gear ran at 100 ft·lbf and about 120 °F. A pooled model will learn "gear A" as a level shift unless features are standardized per gear or regressed on torque.

Signal

Short runs cluster near the end

B Run-7, F Run-7 and D Runs 6–9 are 1–2.5 h long, with lower median temperatures (100–110 °F, since the rig had not warmed up). The operators inspected more often once they suspected damage. Filter out warm-up minutes, and do not use run length as a feature: it would leak the label.

Signal

DM4500 is a cumulative counter

The DM4500 oil-debris bins never decrease within a run (0 negative steps in 23K files), so use differences, not levels. Bins 5–7 are always zero. ICM2 bins hit the 16-bit ceiling (65,535) in up to 0.7% of files; treat those values as clipped.

Signal

Run boundaries cause level shifts

Several CIs shift in level when a new run starts, after the gearbox has been opened and reassembled for photos. That is why the prototype onset in Section 5 lands on run boundaries. Part B needs per-run warm-up trimming or a run-offset term.

Photos

Photo layouts differ by gear

A, B and C have 10 close-up frames of teeth 1–4 plus one overview per tooth. Exp-C switches to two camera setups from Run-5. F has exactly one photo per tooth. Collapse to one label per tooth per inspection: 1,092 tooth-inspections from 2,085 photos.

Section 3

What the photos show (Part A labels)

Every tooth carries a band of micropitting along the tip contact line from break-in onward, so that band cannot count as damage in the rubric. Real spalls grow below it. These crops show the progression the rubric needs to separate.

Section 4

Sensor signals and which indicators track damage

CIs are shown as robust z-scores against each gear's own first 12 h: (x − baseline median) / (1.4826 × MAD). A value of 10 means 10 robust standard deviations from that gear's healthy state. The y-axis uses a signed log scale because some CIs move by 10⁴ or more.

Section 5

Part B prototype: novelty score, onset and life split

A first pass at the proposal's Figures 1 and 3, to check the pipeline end to end. Features are log M6A, M8A, FM4, NA4, energy ratio, TSA kurtosis, TSA RMS and ALR. Each is regressed on oil temperature within the baseline window, standardized, and scored with a Ledoit-Wolf Mahalanobis distance. The score is √(D²/p), roughly the average number of SDs from baseline per feature, smoothed with a 30-minute rolling median. Onset is the first 60 consecutive minutes above the 99.5th percentile of the baseline scores. The onset rule is a placeholder for the proposal's BOCPD.

Section 6

Recommendations for the modeling plan

Part A target

The challenge scores one scalar per 6-hour interval by MSE after an optimal monotonic rescaling, so only the shape of the trajectory counts. Use a gear-level damage scalar (for example the summed spall area over 28 teeth) as a regression target alongside the ordinal class. Evaluate with leave-one-gear-out cross-validation: with four labeled gears, any split within a gear leaks.

Part A rubric

Start with three levels: none, initiation (a flake or pit below the contact band) and spall (a crater). Split spall into moderate and advanced only if the pilot set shows a clear area gap. The automated texture score finds large spalls on A, B and F but misses initiations and shallow spalls (F-19). Use it for triage, not as labels.

Part A imbalance

Use class weights or focal loss, SMOTE only inside the training folds, and report macro-F1 and ordinal MAE rather than accuracy. For ordinal models, CORAL or cumulative-link heads keep predicted classes rank-consistent.

Part B features

Start from M8A, M6A, FM4, NA4 and FLEET_WTMADE (the best trendability), plus DM4500 debris increments. Drop redundant members of each correlation block. Trim the first 20–30 min of every run and add a run-offset term before fitting the baseline covariance.

Part B stability

Report Figure 6 in the final write-up with BOCPD and PELT onsets alongside the persistence rule. The initiation-versus-propagation conclusion should only be stated if the ranking holds across all rows of the variance table.

Fix the Similar Work section

Carpentier, De Temmerman & Verbeke (IDA 2024) used the Scania Component X truck dataset, not the PHM gear data. Describe it as similar methods on a different dataset, and add the NASA Glenn gear-pitting work (Dempsey 2000; Lewicki et al. 2010) as domain references.
